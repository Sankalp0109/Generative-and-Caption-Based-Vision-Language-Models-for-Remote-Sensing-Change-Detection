# RSICC Model Run Reports (prediction sheets)

Qualitative prediction reports from our remote sensing image change captioning (RSICC) experiments. Each page shows a before/after image pair from the test set, the reference caption (where available) and the model's predicted caption.

| File | Model / run | Test set | Pages |
|---|---|---|---|
| `predictions_phase7.pdf` | Phase 7 | LEVIR-CC | 300 |
| `predictions_phase7_second.pdf` | Phase 7 | SECOND-CC | 300 |
| `predictions_phase8.pdf` | Phase 8 | LEVIR-CC | 300 |
| `predictions_phase8_second.pdf` | Phase 8 | SECOND-CC | 300 |
| `predictions_phase_final_finetuneS.pdf` | Final model after SECOND-CC fine-tuning | LEVIR-CC | 300 |
| `SECOND_CC_Test_Predictions_1.pdf` | Final model | SECOND-CC (predictions only) | 43 |
| `SECOND_CC_Test_Predictions_patch_wise.pdf` | Final model, patch-wise inference | SECOND-CC (predictions only) | 43 |

These reports accompany the project reports on change captioning for Indian imagery. They are intended for qualitative inspection of model behaviour, not as a benchmark.

## Source data

The images come from the test splits of the **LEVIR-CC** and **SECOND-CC** datasets and remain subject to those datasets' original terms of use, which restrict use to non-commercial research. Please cite the original datasets if you use these reports.
